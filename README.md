# 백화요란 매크로 (윈도우 · 맥)

G123 「백화요란 검희 연대기」의 **보석채취**(트루 쉐도우 → 농장 → 위탁), **일일 보상**, **유파 쟁탈전**·**학원 쟁패전**·**학원 교류전**·**사검귀 습격**·**흑암 강림**(테스트)을 자동으로 진행하는 프로그램입니다.

**보석채취**
- 설정한 별 이상(기본 ★5)의 **다이아 위탁 농장**이 나올 때까지 목록을 갱신하고, 수익 가산 %가 높은 검희부터 배치합니다. (동시에 위탁할 인원은 1~3명으로 설정)
- 남은 위탁 횟수를 모두 쓰면 **메인 화면으로 돌아와 자동으로 끝납니다**. (위탁 중인 검희의 보상은 시간이 되면 게임에서 자동 지급)
- 도중에 오류가 나도 멈추지 않고, **게임을 새로고침해 메인 화면부터 다시 시작**합니다.
- **즉시 시작** 또는 **매일 정해진 시각 예약**으로 실행할 수 있고, 진행 내역은 날짜별 로그 파일로 남습니다.

**유파 쟁탈전 (테스트)**
- 전장 입장 → 공방 편성 → 호위 자동 공격·이동 → 축복 선택·개인 보상 수령 → 부활 후 재편성 → 경기가 끝나면 메인 화면 복귀까지 자동으로 진행합니다.
- 목표 Pt(기본 500 = 개인 보상 전부)를 채우면 공격을 멈춥니다. 나보다 강한 적이 오면 피합니다.
- **월·화·수 19:55 예약**으로 실행할 수 있습니다.
- 한 계정에서는 보석채취와 유파 쟁탈전이 같은 게임 창을 쓰므로 한 번에 하나만 실행됩니다.

**일일 보상**
- 출석·방치·무료 소환·무료 패키지·유파 출석·임무·메일 등 **매일 무료로 받는 보상**과 도장 연무·오중탑·퀴즈·이벤트 무료 보상을 받습니다.
- 유파 보스 추가 도전·금화 구매·도장 연무 상대 찾기·무혼 결정 구매에 **다이아를 쓸지 계정마다 선택**합니다.
- 방치 수익·오중탑·농장·자양 수프·**채굴(자동 채굴)**·**복주머니 받기·뿌리기**는 고른 간격(시간)마다 따로 하는 **주기 예약**으로 돌릴 수 있습니다. 이벤트 **연회 참가**는 연회가 끝나는 대로 다음 연회에 들어갑니다.

**학원 쟁패전 (테스트)** · **학원 교류전 (테스트)** · **사검귀 습격 (테스트)** · **흑암 강림 (테스트)**
- 학원 쟁패전: **매주 토요일 19:55 예약**으로 유파 쟁탈전처럼 자동 전투. 직업과 직업 스킬 자동 사용.
- 학원 교류전: **매주 목요일 19:55 예약**. 평화 모드엔 시설 점령으로 점수 확보, 난전 모드엔 나보다 약한 적 유파원을 찾아가 공격.
- 사검귀 습격: **금요일 19:55 예약**(경기는 격주). 사사키 코지로의 시련은 음양부 우선으로 모아 납품, 미야모토 무사시의 시련은 식신 보스와 통로의 적 유파원을 차례로 격파.
- 흑암 강림: **매주 월요일 19:00 예약**으로 팀을 만들고 멤버를 불러 한 번 도전.

**여러 계정**
- 계정을 여러 개 등록해 **계정마다 매크로 전용 Chrome**으로 동시에 돌릴 수 있습니다.
- 보석채취 설정·예약은 **모든 계정 공통**(예약 시각에 모든 계정이 함께 시작), 나머지 기능의 설정·예약은 **계정마다 따로**입니다.
- 같은 계정의 예약은 **시각이 먼저 된 것부터 하나씩** 실행합니다. 다른 기능이 돌고 있으면 멈추지 않고 **끝난 뒤** 다음 것을 시작합니다 (보석채취·일일 보상·흑암 강림·공방·유파 예선·주기 예약 모두).
- 예약 시각에 앱이나 컴퓨터가 꺼져 있었으면(절전 포함) 켜지는 대로 같은 순서로 실행합니다. (보석채취·일일 보상은 그날 자정 전까지, 흑암 강림은 그 주 일요일까지)
- **유파 쟁탈전·학원 쟁패전·학원 교류전·사검귀 습격만 예외**로 경기 시각에 시작합니다. 그때 보석채취·일일 보상이 돌고 있으면 멈췄다가 경기가 끝난 뒤 가장 먼저 이어서 하고, 그 밖의 기능이 돌고 있으면 끝난 뒤 바로 시작합니다.
- 계정별 로그인은 **계정 관리** 화면의 **[로그인]** 으로 합니다. G123에 로그인되지 않은(게스트) 계정에서는 매크로가 실행되지 않습니다.
- 그 계정에서 할 수 없는 콘텐츠는 실행해도 바로 **건너뜀**으로 끝납니다. 예: St.1500 전의 농장, 곡옥이 열리지 않은 계정의 채굴, 유파에 가입하지 않았거나 유파가 이번 주 유파 쟁탈전에 신청하지 않은 계정의 유파 쟁탈전. 예약에 걸려 있어도 마찬가지이고, 할 수 있게 되면 그때부터 그대로 동작합니다.

## 설치·실행

### 윈도우
1. 받은 `RyoranMacro-Setup.exe`를 실행합니다.
   - **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명이 없는 프로그램이라 나오는 경고입니다)
2. 자동으로 설치되고 프로그램이 실행됩니다. 바탕화면과 시작 메뉴에 **백화요란 매크로** 바로가기가 생깁니다. (관리자 권한 불필요)
3. 새 버전이 나오면 새 `RyoranMacro-Setup.exe`를 실행하면 됩니다. 설정과 게임 로그인은 그대로 유지됩니다.

### 맥
1. zip 파일을 더블클릭해 압축을 풀고, `RyoranMacro.app`을 **응용 프로그램** 폴더로 옮깁니다.
2. 앱을 처음 열면 "Apple은 'RyoranMacro'에 악성 코드가 없음을 확인할 수 없습니다" 같은 경고가 뜹니다. (Apple 공증을 받지 않은 앱이라 나오는 경고입니다)
   - **완료**를 누른 뒤 **시스템 설정 → 개인정보 보호 및 보안**으로 가서, 아래쪽의 RyoranMacro 항목 옆 **그래도 열기**를 누르고 암호를 입력합니다.
   - 또는 터미널에서 한 번 실행: `xattr -dr com.apple.quarantine /Applications/RyoranMacro.app`

> 지금 쓰고 있는 버전은 창 왼쪽 아래와 창 제목에 `v1.5.1`처럼 표시됩니다 (1.5.1부터). 최신 버전은 [릴리즈 페이지](https://github.com/suhojang/ryoran-macro/releases/latest)에서 확인할 수 있습니다.

## 처음 한 번: 게임 로그인

매크로는 평소 쓰는 Chrome과 분리된 **매크로 전용 Chrome**으로 게임을 조작합니다. 계정마다 전용 Chrome이 따로 있고, 처음 한 번은 그 창에서 로그인이 필요합니다.

1. 왼쪽 메뉴의 **👤 계정 관리**에서 계정을 고릅니다. 계정이 더 필요하면 **[계정 추가]** 를 누릅니다. (이름은 바로 고칠 수 있음)
2. 그 계정의 **[로그인]** 을 누르면 전용 Chrome이 뜨고 G123 **"계정 전환"** 창이 열립니다.
   - 새 Chrome은 처음 열 때 게스트 계정이 새로 만들어져 튜토리얼이 보이는데, 신경 쓰지 않아도 됩니다.
3. **Google·Apple·Passkey·전화번호** 중 원래 쓰던 방법으로 로그인하면 그 계정으로 바뀝니다.
4. 계정 관리에 **✓ 캐릭터 이름 [서버]** 가 표시되면 준비 완료입니다. (로그인은 다음에도 유지됩니다)

- 로그인되지 않은 계정은 위쪽 계정 탭에 ⚠가 붙고, 실행해도 `게스트 계정이라 중단`으로 바로 멈춥니다.
- 두 계정에 같은 G123 계정으로 로그인하면 ⚠ 경고가 뜨고, 둘을 동시에 실행하지 않습니다. (같은 계정에 두 창이 접속하면 서로 연결을 끊음)
- 이미 쓰던 매크로 전용 Chrome의 로그인은 **계정 1**로 그대로 이어집니다.

## 사용법

| 기능 | 방법 |
|---|---|
| 계정 고르기 | 화면 위쪽 **계정 탭**. 실행·로그 칸과 계정별 설정이 고른 계정의 것으로 바뀝니다 (실행 중인 계정은 초록 점) |
| 바로 실행 / 멈추기 | 계정을 고르고 **[즉시 시작]** / **[중지]** |
| 다이아 별 기준 | 설정의 **다이아 별**에서 ★1~★5 선택 (기본 ★5). 선택한 별 **이상**인 농장만 위탁하고, 여러 개면 별이 높은 농장부터 |
| 동시 배치 인원 | 설정의 **동시 배치**에서 1~3명 선택 (기본 3명). 수익 가산 %가 높은 검희부터 이 인원만 위탁하고, 위탁이 끝나면 같은 검희를 다시 보냅니다. 효율 좋은 검희가 적으면 줄이세요. (예: 100% 검희가 1명뿐이면 1명 → 15회 모두 그 검희로. 대신 인원을 줄일수록 끝나는 데 오래 걸림) |
| 매일 자동 실행 | 예약에서 **매일** 체크 후 시각 설정 (예: 01:00). 그 시각에 **모든 계정**이 함께 시작 |
| 기록 보기 | **[로그 폴더 열기]** → 계정별 폴더(`계정1` …)의 `날짜.log` |

보석채취 설정(다이아 별·동시 배치·예약)은 모든 계정 공통입니다.

### 유파 쟁탈전 (테스트)

왼쪽 메뉴의 **⚔ 유파 쟁탈전**에서 설정합니다. 설정·예약은 **계정마다 따로**(위쪽 계정 탭으로 선택)이고, 그 계정이 실행 중일 때는 바꿀 수 없습니다.

| 설정 | 설명 |
|---|---|
| 목표 Pt | 1~600 (기본 500). 이만큼 얻으면 공격을 멈추고 경기가 끝날 때까지 편성만 유지합니다. 개인 보상은 500Pt까지, 무료 부활을 모두 쓰면 최대 600Pt |
| 적 유파원 자동 공격 | 켜면 **나보다 약한** 적 유파원을 공격합니다 (1승 5Pt). 다른 유파원이 공격 중인 시설도 가서 물리친 뒤 호위를 공격해 빼앗고, 나보다 강한 적은 피합니다. 끄면 적 유파원이 있거나 오고 있는 시설엔 가지 않고, 떠난 뒤에 가서 호위만 공격합니다 |
| 공격할 서버 | 유파 이름 옆 [S50]의 숫자. 여러 개는 쉼표로 (예: `50, 52`). 비우면 모든 서버. 목록에 없는 서버 유파원이 있는 시설엔 가지 않습니다 |
| 축복 선택 | **전용 축복 캐릭터**: 체크한 캐릭터의 UR 전용 축복(진화·변이)을 가장 먼저 고릅니다 (여러 명 가능). **우선 종류**: 체크한 종류를 ▲▼로 정한 순서대로 고릅니다. 기본은 야규 쥬베이 · 치명률 > 스킬 데미지 증가 > 치명 데미지 > 데미지 증가 |
| 예약 | **월·화·수** 중 체크한 요일 **19:55**(전장 입장 시작)에 자동 실행. 경기는 20:00 |

자동으로 하는 일:
- 게임 시작(START) 화면, 절전 화면, 공지 팝업을 넘기고 메인 → 유파 → 유파 쟁탈전 → **전장으로** 입장 (입장이 아직 안 열렸으면 30초마다 다시 시도)
- 경기가 시작되면 **게임에 저장된 공방 편성 그대로** 확정. 지휘 부채를 다 쓰면 전투 불능 → 1분 뒤 부활 → 다시 편성 (부활 최대 5회)
- 호위를 공격할 시설을 골라 이동하고, 도착 전까지 **이동 가속을 최대 6회** 사용
- 축복은 **축복 선택** 설정에 따라 다음 순서로 선택 (같은 단계에서는 우선 종류의 위쪽, 그다음 높은 등급)
  1. 체크한 캐릭터의 UR 전용 축복 (진화·변이)
  2. UR 전체 적용 축복 (카드에 "ALL" 표시)
  3. 우선 종류 (등급 무관)
  4. 그 밖의 전체 적용 축복 (등급 무관)
  5. 체크하지 않은 캐릭터의 전용 축복 (고를 게 없을 때만)
- 개인 보상은 받을 수 있을 때마다 수령
- 경기가 끝나면 결과 화면을 닫고 탐험(메인 화면)으로 돌아와 종료

주의:
- **이동 가속은 1회 20다이아**입니다. 아군이 시설을 빨리 점령하면 자주 옮겨 다녀서 다이아가 많이 듭니다. (첫 실전에서 500Pt까지 약 3,500다이아 사용)
- 게임에서 **공방 편성을 한 번 저장**해 두어야 합니다. 빈 팀이 있으면 편성 저장에 실패합니다.
- 그 주에 유파가 유파 쟁탈전에 참가 신청되어 있어야 합니다.
- 테스트 기능입니다. 처음 몇 번은 게임 창을 지켜보면서 사용해 주세요.

왼쪽 메뉴의 **🏫 학원 교류전**. 학원 쟁패전과 같은 방식(호위 자동 공격·약한 적 공격·강한 적 회피·부활)에 다음을 더했습니다.
- **평화 모드(20:00~20:20)**: 본부는 공격받지 않으므로 **시설 확장**. 우리 영지에 붙은 시설의 호위를 공격해 점령합니다. 점령하면 그 시설 점수가 우리 유파로 넘어오므로 점수가 큰 시설(어령단 7·무도장 3·교학관 1 등)과 가까운 시설부터 갑니다.
- **난전 모드(20:20~21:00)**: 지휘 부채를 **적 유파원 공격에만** 씁니다(호위는 공격하지 않음). 나보다 약한 적이 많고 가까운 시설로 가서 공격하고, 지휘 부채가 0이 되면 부활합니다. 나보다 강한 적이 있거나 오면 안전한 시설(우리·동맹 시설 먼저)로 피합니다. 우리 유파가 시설을 빼앗겨 갈 수 있는 곳이 없으면 그 자리에서 기다립니다.
- 강약은 전투력 × 지휘 부채 비율로 비교합니다 (지휘 부채가 100을 넘으면 100으로 계산).
- 편성은 1개: 이번 경기에서 쓴 편성, 없으면 스토리 편성 그대로. 이동 가속은 이동 1회당 최대 6회(1회 20다이아).
- 설정: **적 유파원 자동 공격**(기본 켬. 끄면 평화 모드엔 호위만 공격, 난전 모드엔 공격하지 않음 — 강한 적 회피는 그대로), **공격할 서버**(예: `50, 52`, 비우면 모든 서버).
- 예약: **매주 목요일 19:55**. 유파 신청(목 08:00~18:00)은 회장·부회장 등이 게임에서 하고, 신청·선정되지 않은 주는 건너뜁니다.

### 사검귀 습격 (테스트)

왼쪽 메뉴의 **👹 사검귀 습격**. 경기는 **격주 금요일 20:00~21:00**이고, **사사키 코지로의 시련**과 **미야모토 무사시의 시련**이 한 주씩 번갈아 열립니다. 유파가 그 주에 신청한 시련을 플레이합니다.

사사키 코지로의 시련 — **음양부 우선**:
- 19:55에 시련 화면에 들어가 기다렸다가 20:00에 입장합니다 (편성은 이번 경기에서 쓴 것, 없으면 스토리 편성).
- **음양부**(1개 50Pt, 체력 5)가 나오면(20:10부터 6번, 매번 5개, 지도 중앙) 가장 빨리 갈 수 있는 것을 공격하고, 얻으면 바로 귀환해 본거지에 납품합니다. 본거지 옆 **전송 지점**으로 중앙까지 빨리 가고, 출현 35초 전에는 중앙에서 기다립니다.
- 체력 100은 충전되지 않으므로 남은 음양부 출현에 쓸 만큼 남기고, 나머지로 **음양부 재고가 있는 적 기지 약탈**(1회 체력 1)과 **진주 공격**(1회 체력 1, 1Pt)을 합니다. 진주는 10개 들면 납품합니다.
- 같은 칸의 **나보다 약한 적**(전투력 × 체력%)은 공격해 들고 있는 재료를 빼앗고, 재료를 든 채 **나보다 강한 적**이 가까이 오면 귀환합니다.
- 경기 끝나기 70초 전에는 들고 있는 재료를 모두 납품합니다. 쓰러지면 무료 부활(5회) 뒤 다시 입장하고, 경기가 끝나면 결과 화면을 닫고 메인 화면으로 돌아옵니다.
미야모토 무사시의 시련 — 8관문 미궁:
- 관문마다 **식신 보스**를 유파원과 함께 공격합니다 (10초마다, 체력 1%). 잡으면 **축복**을 고르고(유파 전체 적용 > 개인, 공격 > 스킬 데미지 증가 > 관통 > 명중·속도 > HP > 방어 …), 조우할 유파는 **총 전투력이 가장 낮은 유파**에 투표합니다.
- **조우전(통로)** 에서는 공격할 수 있는 칸(1행이거나 뚫린 칸 옆)의 **적 유파원을 약한 순서로 모두** 공격합니다 (1회 체력 5%). 마지막 관문(자신의 분신)까지 같은 방식입니다.
- 체력이 처음 **1%** 가 되면 **무료 회복 1회**를 씁니다. 1%에서는 적 유파원에게 도전할 수 없어 식신만 공격합니다.

- 예약: **매주 금요일 19:55**. 유파 신청(경기 전날 목요일)은 회장·부회장 등이 게임에서 하고, 경기가 없는 주나 신청하지 않은 주는 건너뜁니다.

### 흑암 강림 (테스트)

왼쪽 메뉴의 **🌑 흑암 강림**. 예약: **매주 월요일 19:00**.
- 리더로 팀을 만들고(바로 가입·공개) 유파 채팅과 전체 채팅에 소환 정보를 보냅니다 (10분마다 다시).
- 나를 포함해 **2명 이상** 모이고 모두 준비하면 도전을 시작합니다. 45분 안에 모이지 않으면 팀을 해산하고 끝냅니다. 그 계정에 경기가 있으면 경기 10분 전까지만 기다립니다 (월 19:00 예약이면 19:45 — 19:55 유파 쟁탈전이 막히지 않게).
- 월요일 19:00에 못 했으면(앱·컴퓨터가 꺼져 있었음 등) 그 주 일요일까지 켜지는 대로 보석채취·일일 보상 다음에 실행합니다. 경기 20분 전부터는 새로 시작하지 않고 경기가 끝난 뒤 시작합니다.
- 보스마다 내 캐릭터를 먼저 출전시키고, 못 잡으면 남은 멤버를 전투력 순으로 출전시킵니다.
- 스테이지를 깬 뒤 쓰러진 멤버가 있으면 회복을 쓰고 출전합니다. 도전이 끝나면 팀을 해산하고, 남은 도전 횟수는 쓰지 않습니다.

- 창을 닫아도 **트레이(윈도우: 작업 표시줄 오른쪽 / 맥: 메뉴바)의 다이아 아이콘**으로 남아 예약을 지킵니다. 아이콘 메뉴의 **종료**로 완전히 끌 수 있고, 끈 동안에는 예약이 동작하지 않습니다 (보석채취·일일 보상·흑암 강림은 다음에 켤 때 실행).
- Chrome이나 게임이 꺼져 있어도 실행 시 자동으로 띄워서 접속합니다.
- 게임의 공지·이벤트 팝업과 절전 화면("슬라이드로 복귀")은 자동으로 닫습니다. 연결이 끊겨 게임 시작(START) 화면이 뜨면 START를 눌러 다시 들어갑니다.
- 매크로용 Chrome 창이 최소화되어 있으면 자동으로 되돌립니다. 다른 창에 가려져 있어도 동작합니다.
- 예약 시각에 컴퓨터가 **절전(잠자기) 상태였거나 앱·컴퓨터가 꺼져 있었으면**, 보석채취·일일 보상·흑암 강림은 깨어나거나 다음에 켤 때 실행합니다. 유파 쟁탈전·학원 쟁패전·학원 교류전·사검귀 습격은 경기 시작 후 1시간이 지나면 건너뛰므로, 그 시간에는 절전되지 않도록 설정해 주세요.
- 놓친 예약은 이 기능이 들어간 1.5.2로 처음 켠 뒤의 예약부터, 예약을 켜거나 시각을 바꾼 경우엔 바꾼 뒤의 예약부터 챙깁니다.

## 문제가 생겼을 때

로그와 화면 기록 위치:

| | 윈도우 | 맥 |
|---|---|---|
| 로그 | `%APPDATA%\RyoranMacro\logs\계정1` … | `~/Library/Logs/RyoranMacro/계정1` … |

- 오류가 나면 로그에 `오류: …`로 남고, 같은 폴더에 그 순간의 화면이 `error-날짜_시각.png`(유파 쟁탈전은 `gvg-`, 학원 쟁패전은 `yc-`, 학원 교류전은 `fz-`, 사검귀 습격은 `sjg-`, 흑암 강림은 `sdsl-`, 일일 보상은 `daily-`로 시작)로 저장됩니다. (같은 오류가 이어지면 연속 3번까지만 저장)
- 오류가 연달아 나면 다시 시도하는 간격을 1분씩 늘려 최대 5분마다 계속 시도합니다. 아침까지 **실행 중**으로 남아 있으면 로그를 확인하고, 필요하면 **[중지]** 를 누르세요.
- 로그에 이런 오류가 반복되면 직접 조치가 필요합니다.
  - `Chrome(chrome.exe)을 찾을 수 없음` (윈도우): Chrome이 기본 위치(Program Files 또는 사용자 AppData)에 설치되어 있어야 합니다.
  - `게스트 계정이라 중단`: 그 계정의 전용 Chrome이 G123에 로그인되어 있지 않습니다. 계정 관리에서 [로그인]으로 로그인하세요.
  - `메인 화면에 트루 쉐도우 버튼이 없음`: 매크로 전용 Chrome에 다른 계정(또는 트루 쉐도우가 아직 열리지 않은 계정)이 로그인되어 있습니다. 계정 관리에서 로그인된 캐릭터를 확인하세요.
  - `게임 창이 화면에 보이지 않음`: 매크로용 Chrome 창을 화면에 보이게 두면 다음 재시도 때 이어서 진행합니다.

## 삭제

### 윈도우
**설정 → 앱 → 설치된 앱**(또는 제어판의 프로그램 제거)에서 **백화요란 매크로 → 제거**를 누릅니다.
- 제거 중 **"설정, 로그, 매크로용 Chrome 로그인 정보도 함께 삭제할까요?"** 창이 뜹니다. **예**를 누르면 모두 지우고, **아니요**를 누르면 다시 설치했을 때 그대로 사용할 수 있습니다. (먼저 매크로용 Chrome 창을 닫아 주세요)

### 맥
1. 메뉴바의 다이아 아이콘 → **종료**로 앱을 끈 뒤, 응용 프로그램 폴더의 `RyoranMacro.app`을 휴지통에 넣습니다.
2. 설정·로그·로그인 정보까지 지우려면 Finder에서 **이동 → 폴더로 이동**(⇧⌘G)으로 아래 폴더를 찾아 지웁니다.
   - `~/Library/Application Support/RyoranMacro`
   - `~/Library/Logs/RyoranMacro`
   - `~/.ryoran-macro`
