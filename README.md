# 백화요란 매크로 (윈도우)

G123 「백화요란 검희 연대기」의 **보석채취**(트루 쉐도우 → 농장 → 위탁)를 자동으로 진행하는 윈도우용 프로그램입니다.

- ★5 다이아 위탁 농장이 나올 때까지 목록을 갱신하고, 수익 가산 %가 높은 검희부터 배치합니다.
- 남은 위탁 횟수를 모두 쓸 때까지 반복하고, 위탁이 끝나면 보상 팝업을 닫아 수령합니다.
- **즉시 시작** 또는 **매일 정해진 시각 예약**으로 실행할 수 있고, 진행 내역은 날짜별 로그 파일로 남습니다.

## 다운로드

**[RyoranMacro-win32-x64.zip 받기](https://github.com/suhojang/ryoran-macro/releases/latest/download/RyoranMacro-win32-x64.zip)** (약 160MB)

## 설치·실행

1. zip 파일의 압축을 원하는 폴더에 풉니다.
2. 폴더 안의 `RyoranMacro.exe`를 실행합니다. (Node.js 등 따로 설치할 것은 없습니다)
   - 처음 실행할 때 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명이 없는 프로그램이라 나오는 경고입니다)
3. PC에 **Google Chrome**이 설치되어 있어야 합니다.

## 처음 한 번: 게임 로그인

매크로는 평소 쓰는 Chrome과 분리된 **매크로 전용 Chrome**으로 게임을 조작합니다. 처음 한 번은 이 창에서 로그인이 필요합니다.

1. 프로그램에서 **[게임 창 열기]** 를 누릅니다.
2. 열린 Chrome 창에서 **본인 G123 계정으로 로그인**합니다.
3. 게임 메인 화면에 본인 캐릭터 이름이 보이면 준비 완료입니다. (로그인은 다음에도 유지됩니다)

## 사용법

| 기능 | 방법 |
|---|---|
| 바로 실행 | **[즉시 시작]** |
| 멈추기 | **[중지]** |
| 매일 자동 실행 | 예약에서 **매일** 체크 후 시각 설정 (예: 01:00) |
| 기록 보기 | **[로그 폴더 열기]** → `날짜.log` |

- 창을 닫아도 작업 표시줄 오른쪽 **트레이(다이아 아이콘)** 에 남아 예약을 지킵니다. 트레이 아이콘 우클릭 → **종료**로 완전히 끌 수 있고, 끄면 예약도 동작하지 않습니다.
- PC가 절전 상태면 예약 시각에 실행되지 않고, 깨어난 직후 한 번 실행됩니다.
- Chrome이나 게임이 꺼져 있어도 실행 시 자동으로 띄워서 접속합니다.
- 게임의 공지·이벤트 팝업과 절전 화면은 자동으로 닫습니다.

## 문제가 생겼을 때

- 중간에 멈추면 로그 폴더(`%APPDATA%\RyoranMacro\logs`)에 그 순간의 화면이 `error-날짜_시각.png`로 저장됩니다. 로그 파일과 함께 확인해 주세요.
- `Chrome(chrome.exe)을 찾을 수 없음`: Chrome이 기본 위치(Program Files 또는 사용자 AppData)에 설치되어 있어야 합니다.
- `메인 화면에 트루 쉐도우 버튼이 없음`: 매크로 전용 Chrome에 다른 계정(또는 트루 쉐도우가 아직 열리지 않은 계정)이 로그인되어 있습니다. [게임 창 열기]로 계정을 확인하세요.

## 주의

매크로 사용은 게임 이용약관에 위반될 수 있으며, 계정 제재 등 모든 책임은 사용자 본인에게 있습니다.
